Datenschutzerklärung

Lernzettel Pi ist ein privates Hilfsprogramm, das nur von seinem Besitzer genutzt wird.

Welche Daten werden genutzt?

Die Anwendung liest und schreibt mit Zustimmung des Besitzers Dateien in dessen eigenem Google-Drive-Ordner. Diese Dateien werden nur auf dem privaten Gerät des Besitzers verarbeitet.

Weitergabe

Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung verwendet. Es gibt keine Nutzerkonten, kein Tracking und keine Cookies.

Nutzung von Google-Daten

Die Nutzung von Daten, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
